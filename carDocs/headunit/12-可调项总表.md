> 汇总本车机提取物里能「读/写、开关、设值」的东西，按域分组。证据来自 REA 反编译

## 一、音频（最丰富的一块）

### 1.1 车机 DSP HAL（`android.hardware.dsp.V1_0.IDspHwDevice`）
在 HIDL 层可直接调：

| 方法 | 作用 |
| --- | --- |
| `setPeq(PeqParams)` | **参量均衡（PEQ）**：per_band_cfg / pregain / coeffs / device / enable |
| `setDspEffect(int effectType, int value)` | 音效（见 `EffectType`） |
| `setChGain(int[] ch, int gain)` | 各声道增益 |
| `setDelay(int[] ch, int delay)` | 声道延时（声场） |
| `setVolume/setVolumeOffset(int, int)` | 音量/偏置 |
| `setMute(int, boolean)` | 静音 |
| `setDuck(int, boolean, int)` / `setMediaDuck(boolean)` | **闪避**（导航/提示压低媒体） |
| `setSDVCLevel(int)` | 车速音量补偿 |
| `setSource(int, boolean, boolean)` | 音源切换 |
| `onAudioFocusChange / onExtAudioFocusChange` | 音频焦点 |

`EffectType`（音效项）：`EQ_MODE`、`EQ_BAND1..6`、`FADER`、`BALANCE`、`BMT_BASS/MIDDLE/TREBLE`、
`LOUDNESS`、`DTS_MODE`、`SURROUND`、`BEST_LISTENING`、`KTV_MODE`、`PDC_LEVEL`、`CHIME_LEVEL`、`BEEP_ENABLE`。
`EQMode`：`STANDARD / POPULAR / ROCK / JAZZ / CLASSICAL / VOICE / CUSTOM`。

### 1.2 OneOS 音频 `com.geely.os.audio.IGlyAudio`（在 `OneOS-InputService`）
```
均衡：getNumberOfBands/getBandLevelRange/getPresetName/getCurrentPreset/usePreset/setBandLevel
      getLMHBandLevel(Range)              // 低中高（Loudness-Mid-High）
声场：getFaderLevel/setFaderLevel、getBalanceLevel/setBalanceLevel
音效：isLoudnessEnabled/setLoudnessEnable、get/setDtsSoundMode、get/setSurroundSoundOnOff、
      Harman(ClariFi/Surround) 开关、get/setEffectEnhanceMode
补偿：SpeedCompensatedVolume 开关 + 补偿等级、get/setNaviVoiceMixMode（导航语音混音模式）
外放：get/setExternalSpeakers{Switch,Volume,MediaPlayMode}
分组：get/setVolumeByUsage、setGroupMuteBy{GrupId,StreamType}、getMax/MinVolumeByUsage
其它：setMicVolumeCallbackSwitch
支持性：isEqualizerSupported/isFaderSupported/isBalanceSupported/isHarmanSettingSupported…
```
> 这是**最像「音频设置页」的完整可调面**（EQ/声场/响度/DTS/环绕/Harman/车速补偿/导航混音/外放）。

### 1.3 音频扩展服务
- `com.autolink.audioextservice.AudioInterfaceManager`
  `get/setCustomSettingEnable(int,bool)`、`get/setCustomSettingValue(int,int)`、
  `get/setGroupVolumeForUsage`、`isGroupMuteForUsage`、`setDigKeyVolumeLimit(bool)`。
- `com.autolink.audioextservice.VehicleFuncManager`
  `execAmbientOnOff`、`execDigKeyVolumeLimit`、`execHeadrestMode`、`execMiscEvent`、`execSceneModEvent`、
  `get/setRestModeVolumeLimit`、`storeDrivingModeSettings/getStoreDrivingMode`、`playDriveModeEffect`；
  `getAdaptationPropId(int)`（功能→车机属性 ID 映射）。
- `com.autolink.audioextservice.IAudioExtControl`：频谱/增益/防抖/语音灯（见 [`11`](11-音乐律动氛围灯.md)）。
- `com.autolink.adapterbinder.IAudioExtService`、`SoundEffectsHelper`（触摸音效 SoundPool）。

## 八、可达性小结（第三方）

| 域 | 通道 | 第三方 |
| --- | --- | --- |
| 氛围灯/灯光秀 | `ECarXCarAmbliManager` / `LightShowImpl` | 需厂商/Car 权限（待实测） |
| 音乐律动 | `IAudioExtControl`（注册回调可读频谱；设参数需绑定服务） | 读较易，写需权限 |
| 音频 EQ/声场/混音 | `IGlyAudio`（OneOS）/ DSP HAL | OneOS 需系统权限；DSP HAL 为 HIDL（需 HAL 权限） |
| HUD | `IHUD` / `HUDInteraction` | adaptapi 可用性待测（`FunctionStatus`） |
| 车灯功能号 | `ILamp`（多只读） | 需权限 |
| 车辆功能管理 | `ecarx.car.hardware.vehicle.*` | 需 Car/Vendor 权限 |
| 工程模式 | `com.desaysv.engmode`（exported） | `am start` 可开；内部操作需口令/产线 |
| 车机设置页 | `com.geely.settings` | 用户可点；第三方不能直接改 |

> 结论：**可调项非常多**，但「第三方能否程序化改」取决于 Car/Vendor/OneOS 权限；
> 单纯**只读探测**（读支持状态与当前值）最容易，建议先做只读，再按权限逐个放开写入。

## 九、建议下一步（可选）
