# 启动界面与品牌资源

> 问题：这台车机开机时显示的「启动界面」是什么。
> 结论：**Android 层可见的「品牌启动画面」是 Launcher 的 splash（`csd_logo` = LYNK & CO）**；
> 更早的 bootloader / 开机动画（bootanimation）**不在本次提取范围内**（在未拉取的分区）。

## 一、启动画面（Launcher splash）

`/system/priv-app/OneOS-Launcher3`（`com.android.launcher3`）里：

- `res/layout/splash_screen.xml`：整屏 `ImageView`，背景 `@drawable/csd_logo`、`scaleType=center`。
- `res/drawable/csd_logo.webp` → 就是 **LYNK & CO 字标**（黑底 + 灰白斜向箭头/切角）。
  已转存为 [`assets/launcher-splash-csd_logo.png`](assets/launcher-splash-csd_logo.png)。

```
ImageView(scaleType=center)
  background = @drawable/csd_logo   →  res/drawable/csd_logo.webp  (LYNK & CO)
```

> 这是 Android 的「启动窗口(starting window)」：桌面进程冷启动到首帧之间，系统先画这张品牌图。
> 也就是说**领克标在启动时出现，是 Launcher3 的 splash，不是独立的开机动画 App**。

同包其它品牌/入口资源：
`ic_car_link_logo`、`ic_hi_link_logo`、`ic_flyme_link_logo`、`ic_psd_car_link_logo`、`ic_psd_hi_link_logo`
（手机互联入口）；`ic_carlink.webp` 是 `com.geely.view.carlink.CarLinkStatusActivity`（label「手机互联」）的图标。

## 二、真正意义上的「开机动画」不在本次提取里

整机提取只包含 `/system`、`/system_ext`、`/product`、`/vendor` 的 **app 与 framework/permissions/getprop**，
**没有 `/system/media`、`/product/media`、也没有 logo/splash 分区**，因此：

- **Android bootanimation**（`bootanimation.zip`，通常 `/system/media` 或 `/product/media`）—— **未拉取**；
- **车机/QNX 侧的开机 logo**（一般在 `logo`/`splash` 分区）—— **未拉取**。

要拿到它们，在车机上执行（找同款车机时）：

```sh
adb shell ls -l /system/media /product/media 2>/dev/null
adb shell find / -name 'bootanimation.zip' 2>/dev/null
adb pull /system/media/bootanimation.zip            # 或 /product/media/...
adb shell ls -l /dev/block/by-name | grep -i -E 'logo|splash'
# 需要时再从对应分区 dd 出 logo 镜像
```

## 三、开机后依次出现的东西

| 阶段 | 组件 | 证据 |
| --- | --- | --- |
| Android 启动窗口 | `com.android.launcher3` 的 `splash_screen.xml`（LYNK & CO 标） | `res/layout/splash_screen.xml` |
| 桌面（Home） | `com.android.launcher3.Launcher`（category `HOME`/`LAUNCHER`，Flyme Auto 定制） | manifest |
| 首次开机引导 | **`com.geely.provision`（label「新手引导」）**，`activity.HelloActivity` | `aapt2 dump badging` |
| 屏保 | `com.geely.screensaver`（`MainActivity`） | badging |
| OTA 开机提示 | `com.geely.upgrade` 的 `window_boot_remind.xml` / `view_startup_checking.xml` | 资源名 |
| 主题/壁纸 | `com.geely.theme`（label「主题商城」） | 见下 |

## 四、「新手引导」`com.geely.provision`（首次开机的完整流程）

REA 分析（4937 类）显示的流程类：
`HelloActivity → LoginActivity → WaitLoginActivity → FaceEnrollActivity / FaceEnrollSuccessActivity /
FaceReEnrollActivity → SafetyActivity → WifiActivity / WifiExActivity → SubActivity`。
用户协议 `DialogAgreement*`、`AgreementBean`；`SafetyAdapter` + `assets/safety_list.json`（安全须知视频列表）；
`DialogVideoGuideActivity` + `VideoAdapter/VideoViewAdapter`（引导视频）。

带 `libpag.so`（腾讯 **PAG** 动画）与 `libffavc.so`（FFmpeg 解码）→ **新手引导用 PAG/视频播放**。

> 正常用户（`DEVICE_PROVISIONED=1`、`persist.sys.device_provisioned=1`）**只会看到一次**，之后每次开机直接进桌面。
> 想看它：`adb shell am start -n com.geely.provision/.activity.HelloActivity`。

## 五、品牌主题与壁纸（`com.geely.theme`，label「主题商城」）

`assets/` 里同时带多种品牌皮肤：
- `StatusWallpaper/`：`default_wallpaper_bg`、**`lynk_black_gw`/`lynk_black_yg`/`lynk_white_gw`**、
  `sport_dark`/`sport_light`、`geely_four_13_psd_dark|light`。
- `ScreenProtection/`：`default_screenProtection_01/02`（屏保图）。
- `res/58.mp4` 等（主题动画/视频）。

另有 prop：`persist.sys.theme=2`、`theme.check.sys.boot=1` → **主题可在开机时生效**。

## 六、一句话回答

**你开机看到的领克标 = `com.android.launcher3` 的启动 splash（`csd_logo.webp`，LYNK & CO）**；
首次开机的「新手引导」是 `com.geely.provision`（HelloActivity，PAG/视频）；
而车机真正的**开机动画/开机 logo 文件在未拉取的 media/logo 分区**，本次无法直接给出，需按第三节命令补拉。
