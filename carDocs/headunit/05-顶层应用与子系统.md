# 顶层应用与其它子系统（逐包速查）

> 每个包的完整类清单在 `evidence/<包名>/classes.json`（REA 输出），manifest 类型信息在 `package.json`。
> 这里只列**结构性关键类**与结论。

## 一、服务/代理层（车机能力的真正宿主）

### `ECarXCarService`（`com.ecarx.car`，1628 类）
- `com.ecarx.car.ECarXCarService`、`CarServiceBase`、`CarServiceUtils`、`CarSignalService`、
  `ECarXCarInfoService`、**`ECarXCarHardKeyService`**、`ECarXCarLogService` / `LogDIDService`、
  `hal.HalServiceBase` / `hal.SignalHalService`。
- 内嵌 `ecarx.dimprotocol.*`（`IDIMProtocolService`、`IDimNaviService` 等）、`ecarx.csd/csdm/dtcnl`、
  **`ecarx.fw.api.ECarXAPI` / `ICreator`**。
- → 这是 **ECARX 侧 CarService 插件**：`ecarx.car.*` / `ecarx.fw.api.*` / `ecarx.dimprotocol.*` 的服务端。
  「硬按键」「车辆信号」「DIM 协议」在这里被真正实现。

### `CarProxyService`（`com.autolink.carproxyservice`，1840 类）
- `CarProxyService`、`CarProxyServiceBinder`；内嵌 `com.autolink.adapterbinder.*`
  （`ICarProxyService`/`ICarProxyCallback`、`IAudioExtService`、`IHardKeyService`、
  `IDimNavi/Media/PhoneCallInteractioncService`、`IOccAudioService`、`ITcamService`、`IOTAService`…）。
- VDBus 侧：`com.desaysv.ivi.vdb.client.bind.VDServiceDef`、`service.base.VDService`、`utils.VDServiceUtil`。
- → **Autolink/德赛的适配代理**：把 VDBus + adapterbinder 的能力暴露给系统应用。

### `OneOS-ApiService`（`com.geely.service.oneosapi`，937 类）
- OneOS 能力枢纽（`IServiceManager`）。内嵌 `com.geely.lib.oneosapi.*` 的模型
  （`navi.model.base.*`：`RoadClassType`、`ScreenStatusTypes`、`SourceType`、`PoiPageStatus`…）、
  `notification.PanelType`、`ueengine.constant.UeSceneType`。
- → DiPlay 之前用它拿 `getService(1)`/`getService(41)`；第 41 号（setting manager）为 null 的结论仍成立。

### `ECarXCarService` 与 `CarService`/`CarShell`
- `CarService`（`com.android.car`，3178 类）：AOSP CarService + 德赛/ECARX 扩展（`com.desaysv.ivi` 261 类）。
- `CarShell`（`com.android.shell` 车机版）、`CarFrameworkPackageStubs`。

## 七、`desaysv` 手机互联适配层细节（`PhoneLinkAdaptorLibManager`）

除能力查询外，还有一批显式「开关」方法（`evidence/inspect/phonelinkadaptor.Manager.json`）：
`setBtLoopConnect` / `cancelBtLoopConnect`（蓝牙回连）、`setPlayMedia(int)`、`setAsrStatus(int)`、
`stopNativeNavi()` / `stopNativeVr()`、`setUSBControl()`、`queryCarGear()`；
回调 `onVrRequestChange` / `onXCallStatusChange` / `onVehicleSpeedChange` / `onAll...`。
→ 互联 App（CarLink/HiCar/FlymeLink）都靠这套适配层与车机通信。
