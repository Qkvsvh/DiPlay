# 音乐律动氛围灯（Music Light Show）

> 结论：**有。** 车内氛围灯支持「音乐律动 / 语音律动」，实现在
> `com.autolink.audioextservice`（`AudioExtService` 进程）的 **`VisualizerManager`** 里：
> 用 Android `Visualizer` 抓当前播放音频的频谱 → 按频段取幅度 → 归一化成 0‑15 级 → 打包 protobuf
> 经 **FDBus** 下发给灯光控制器。
> 证据：REA 反编译 `evidence/inspect/amb.*`、`evidence/method/amb.VM_*.json`；常量 `dexdump`。

## 一、它是怎么「律动」的（链路）

```
当前音频会话(sessionId) ── android.media.audiofx.Visualizer(1024 点)
        │  每 20 ms 取一次波形/FFT    (VisualizerManager.PERIOD = 20ms)
        ▼
processSentMusicData(float[] fft)
   · 1024 点 FFT，频率分辨率 38.986355 Hz/点
   · 对每个「中心频段」取区间最大值 → sectionMax
   · 幅度>4.0 时叠加等响度加权 mLoudnessWeightedGain[]
        ▼
   mSentPreciseData[i] = (sectionMax * 15 / mBaseAmplitude) * mMusicAmplitudeGain[i]   (夹到 0..15)
        ▼
   mSentByte[i] = round(...)  → byte 频谱数组（16 级亮度）
   maxFFTFreq / maxFFTAmp = 最强频段的下标与幅度
        ▼
MusicLightShowBean → InteractionProto.MusicLightShow (protobuf)
   {spectrum_1/2, max_fft_frequency_1/2, max_fft_amplitude_1/2,
    down_sampling_amplitude_1/2, state_flag_*, time_flag_*}
        ▼   FdbusClientInstance.send(builder, false)（仅当 氛围灯总开关 && 音乐律动开关 打开）
灯光控制器 / 氛围灯 ECU  → 灯带按频谱「跳」
```

关键代码（REA 反编译，节选）：

```java
// initVisualizer(sessionId)
mCaptureSize = Visualizer.getCaptureSizeRange()[1];   // 1024
mVisualizer.setScalingMode(1); mVisualizer.setEnabled(true); startGetVisualizer();

// processSentMusicData(...)
bytes[i] = sectionMax;                                   // 每段最大值
if (bytes[i] > 4.0f) bytes[i] += mLoudnessWeightedGain[i];
mSentPreciseData[i] = ((bytes[i]*15f)/mBaseAmplitude) * mMusicAmplitudeGain[i];  // 归一到 0..15
mSentByte[i] = (byte)Math.round(mSentPreciseData[i]);

// sendMusicData(...)
if (!mAmbientOnOffAll || !mAmbientOnOffMusic) return;    // 双开关
bean.setSpectrum_1|2(...); ... mFdbusClient.send(bean.getMusicLightShow(), false);
```

- **双缓冲**：`flagToSend` 在 `spectrum_1` / `spectrum_2` 间切换，避免发送与填充冲突。
- **更新率**：`PERIOD = 20 ms`（50 Hz）；灯光秀时另有 `LIGHT_SHOW_UPDATE_DELAY = 50ms`、退出延迟 `80ms`。

## 二、频段 / 增益按车型分档

`initCaptureInfo()` 按车型选择**频段表**：

| 分支 | 频段表 | 说明 |
| --- | --- | --- |
| `isG733VehicleType()` | `mG733MusicFreqSection` / `mG733VoiceFreqSection` + `mG733MusicSectionZoneGain` / `mG733VoiceSectionZoneGain` | G733 车型 |
| `isHighAmbient()` | `mHighMusicFreqSection` | **高配氛围灯** |
| 其它 | `mLowMusicFreqSection` | 低配 |
| 语音 | `mVoiceFreqSection` | 语音律动 |

- 每个「段」由 `FreqSectionInfo`（`startFreqPoint`/`endFreqPoint`/`centerFreqPoint`/`containFreqPointCount`/`containFreqFirstIndex`）描述，
  中心频率表 `mCustomCenterFreq`，对应增益 `mMusicSectionZoneGain` / `mVoiceSectionZoneGain`。
- **段 → 灯区映射**：`mMusicGainSectionZone[]`（`[6]` 为段数）与 `sectionZone` 把频段映射到灯的物理分区。
- 幅度增益：`mMusicAmplitudeGain[]` / `mVoiceAmplitudeGain[]`；防抖：`mVoiceAntiShakeDegree`；
  等响度：`mLoudnessWeightedGain[]`；基线：`mBaseAmplitude` / `mMaxAmplitude`。

## 三、语音律动（说话时也亮）

`updateVrState(int)` + `VoiceLightShowBean`：语音状态机
`VR_STATUS_{IDLE=0, LISTENING=1, PROCESSING=2, PROMPTING=4, END_SPEAKING=5, WAITING=MIN}`、
百度 VR 状态 `BD_VR_STATUS_{IDLE,LISTENING,LISTENING_PSG(副驾),TTS}`、
`SPEECH_STS_{NONE,ASR,ASR_PSG,TTS}`（含**副驾语音**）。
`mVoiceStateFlag/mVoiceAsrFlag/mVoiceTtsState/mVoiceNluState` → 语音灯效；听/处理/播报/说话结束各有灯态与延迟
（`VR_DELAY_LISTENING_ENTER=8`、`VR_DELAY_LISTENING_IDLE=7`）。

## 四、开关与设置键

`updateAmbientOnOff(int key, boolean state)`：

| key | 常量 | 设置键（ContentResolver） |
| --- | --- | --- |
| 0 | `AMBIENT_ALL_KEY` | `ext.audio.ambient.status/0`（氛围灯总开关） |
| 1 | `AMBIENT_MUSIC_KEY` | `ext.audio.ambient.status/1`（**音乐律动**） |
| 2 | `AMBIENT_VOICE_KEY` | `ext.audio.ambient.status/2`（**语音律动**） |

- 发送前判断 `mAmbientOnOffAll && mAmbientOnOffMusic`；关掉时发 `sendLightShowFlag(1)` + `sendEmptyMusicData()`。
- 音频侧：`CarAudioManager.CarAudioFocusCallback` / `CarExtVolumeCallback`，`isBtMusic`（蓝牙音乐单独 session，
  `BT_MUSIC_PACKAGE_NAME="com.android.bluetooth"`）。
- 车型/氛围灯配置 prop：`persist.vendor.ecarx.cfg.cc.interior.illumination`、`persist.vendor.ecarx.cfg.cc.vehicle.type`；
  调试开关 prop：`tmp.autolink.extaudio.debug`。

## 五、可调参数 & 第三方取数（`IAudioExtControl`）

`com.autolink.audioextservice.IAudioExtControl`（`AudioExtControlService` 提供）：

```
setSpectrumMode(int,int) / getSpectrumMode(int)     频谱模式
setFreqGain(int,float)   / getFreqGain(int)         每段增益
setAmplitudeGain(int,float) / getAmplitudeGain(int) 幅度增益
setSectionZone(int)      / getSectionZone()         段→灯区
setUseSectionMax(bool)   / getUseSectionMax()
setLoudnessWeighted(bool)/ getLoudnessWeighted()
setAntiShake(bool) / setAntiShakeDegree(float) / getAntiShake()/getAntiShakeDegree()
setVoiceBaseDB(int) / getVoiceBaseDB()  setVoiceLightDegree(float) / getVoiceLightDegree()
registerDataCallback(IVisualizerCallback) / unregisterDataCallback(...)   // 拿实时频谱 byte[]
```

`IVisualizerCallback.onDataChanged(byte[] data)` → 外部可获得**实时频谱字节数组**（0‑15 级/段）。

## 六、灯光侧接口（怎么被点亮的）

在 `ecarx.car.hardware.vehicle.ECarXCarAmbliManager`（见 [`10-氛围灯与灯光.md`](10-氛围灯与灯光.md)）：

- `CB_AmbLiMusicShowTyp(int)` / `ManagerId_cbamblimusicshowtyp = 557877417` —— 音乐秀类型
- `CB_AmbLiMusicCorrln(int)` / `ManagerId_cbamblimusiccorrln = 557877451` —— 音乐联动开关
- `CB_AmbLiSpeechCorrln(int)` = 557877421 —— 语音联动
- `CB_Amb_DoorOpenMusicAudTyp(int)` = 557877459 —— 开门音乐/音效
- `CB_Amb_MusicShowPassExcluSwt(int)` = 557877453—— 音乐秀是否排除副驾
- 车信号 `AmbLiShowTyp`（氛围灯显示类型）
- 灯光秀数据另走 `ManagerId_cblightshowdata = 561023163` / `CB_LightShowData(byte[])`
- 灯光秀时用 `mFdbusClient.sendLightShowFlag(...)`（`LIGHT_SHOW_FLAG_MUSIC_START/STOP=1/2`、`VOICE_START/STOP=3/4`）

## 七、一句话 & 验证

**「律动」= 抓当前音频会话的 1024 点 FFT → 按车型频段表取每段最大值 → 增益/等响度归一化到 0‑15 级 →
打包 `MusicLightShow` protobuf 经 FDBus 发给灯光 ECU**；另有语音律动（含副驾）。开关是
`ext.audio.ambient.status/0|1|2`，参数由 `IAudioExtControl` 调，频谱可由 `IVisualizerCallback` 获取。

```sh
# UI（MyCar → 灯光 → 氛围灯 / 音乐律动）
adb shell am start -n com.geely.settings/.MainActivity
# 开关存储
adb shell settings get system ext.audio.ambient.status/1     # 或 secure/global，看实现
# 全局调试日志
adb shell setprop tmp.autolink.extaudio.debug 1
adb logcat -s AES_VisualizerManager:V AES_DEBUG:V
# 配置
adb shell getprop persist.vendor.ecarx.cfg.cc.interior.illumination
adb shell getprop persist.vendor.ecarx.cfg.cc.vehicle.type
```

> 注：`PERIOD=20ms`（50Hz）；FFT 分辨率 `38.986355 Hz/点`；采样点 `1024`（`Visualizer.getCaptureSizeRange()[1]`）。
> 具体到 FX11 用哪张频段表（G733 / 高配 / 低配），取决于 `persist.vendor.ecarx.cfg.cc.vehicle.type` 与
> `isHighAmbient()`，需上车读 `getprop` 确认。
